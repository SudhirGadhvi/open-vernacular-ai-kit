# v1.4.0 Release Notes

`v1.4.0` focuses on practical adoption: a clearer Gujarati support/ecommerce story, stronger Hindi
beta support-chat normalization, and a copy-paste API deployment path.

## Highlights

- Added a Gujarati support/ecommerce case study grounded in committed uplift metrics.
- Hardened Hindi beta normalization for noisy support and ecommerce phrases.
- Added a FastAPI/Docker quickstart with local smoke checks and a small Python client.
- Added Hindi beta readiness guidance with examples and focused validation commands.
- Added vNext/release-readiness documentation to make release preparation reproducible.

## Hindi Beta Improvements

The Hindi beta profile now handles more support-chat abbreviations and ecommerce phrasing
deterministically, including tokens such as:

- `nhi`
- `kr`
- `rha`
- `bheja`
- `koi`
- `dusra`
- `mangwana`

Example:

```bash
gck codemix --language hi --translit-mode sentence "coupon code bilkul work nhi kr rha"
```

Expected output:

```text
coupon code बिल्कुल work नहीं कर रहा
```
